## Overview

**JobSort** is a modern, AI-powered job application tracker that automatically syncs with your Gmail to organize and track your job search. No more manual data entry — let AI do the heavy lifting.

**Live Demo:** [https://jobsortapp.online](https://jobsortapp.online)

---

## Features

### Authentication
- Google OAuth 2.0 login
- Secure JWT-based sessions
- Email/password registration fallback

### Gmail Integration
- **Auto-Sync:** Automatically import job applications from Gmail
- **AI-Powered Parsing:** Extracts company name, position, and status from emails
- **Smart Filtering:** Distinguishes job applications from job alerts
- **Start Date Selection:** Choose when your job search began
- **Real-Time Progress:** Calming progress dialog with animated messages

### Application Management
- **Excel-Style Grid:** Sortable, filterable, and searchable table
- **Bulk Actions:** Select, delete, or update status for multiple applications
- **Status Tracking:** Applied → Screening → Interview → Offer → Accepted/Rejected
- **Timeline View:** Complete history of each application's journey

### Analytics Dashboard
- **Status Distribution:** Pie chart showing application breakdown
- **Monthly Trends:** Area chart for application activity over time
- **Weekly Activity:** Bar chart for weekly application volume
- **Key Metrics:** Interview rate, offer rate, response time

### User Experience
- **Dark Mode:** Beautiful Apple-style dark theme
- **Mac-Style UI:** Native-looking title bar with traffic lights
- **Responsive Design:** Works on desktop and tablet
- **Calming Sync Messages:** Rotating messages during Gmail sync
